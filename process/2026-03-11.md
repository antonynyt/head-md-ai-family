**Hardware note**: `speexdsp` is written in optimised C and was originally made for VoIP on phones, so CPU load on a Pi is negligible. The only thing to tune after first run is `AEC_DELAY` — start at 320 (20ms), and if you still hear bleed, increase it in steps of 160.
