## Hardware Wiring

### SPH0645 Microphone
| SPH0645 Pin | Pi 5 Pin | GPIO |
|-------------|----------|------|
| 3V | Pin 1 | 3.3V |
| GND | Pin 6 | GND |
| BCLK | Pin 12 | GPIO 18 |
| DOUT | Pin 38 | GPIO 20 |
| LRCLK | Pin 35 | GPIO 19 |
| SEL | GND | (left channel) |

### PAM8302A Speaker
| PAM8302A Pin | Pi 5 Pin | Notes |
|--------------|----------|-------|
| VIN | Pin 2 | 5V |
| GND | Pin 6 | GND |
| A+ | GPIO 12 (Pin 32) | Via RC filter |
| A- | GND | |
| OUT+ / OUT- | Speaker | Differential output |

**RC Filter** (between GPIO 12 and A+):
```
GPIO 12 ── 80Ω ──┬── PAM8302A A+
                 │
               100nF
                 │
                GND
```
> Use two 47Ω resistors in series to make ~94Ω if needed.

## /etc/asound.conf

```
pcm.mic_hw {
    type hw
    card 0
    device 0
    channels 2
    format S32_LE
    rate 48000
}

pcm.mic_sv {
    type softvol
    slave {
        pcm "mic_hw"
    }
    control {
        name "Mic Capture Volume"
        card 0
    }
    min_dB -3.0
    max_dB 20.0
    resolution 256
}

pcm.pwm_sv {
    type softvol
    slave {
        pcm "hw:1,0"
    }
    control {
        name "Speaker Volume"
        card 1
    }
    min_dB -40.0
    max_dB 0.0
    resolution 256
}

pcm.!default {
    type asym
    playback.pcm "pwm_sv"
    capture.pcm "mic_sv"
}
```

## Useful Commands

### Check devices
```bash
arecord -l          # List capture devices
aplay -l            # List playback devices
```

### Microphone
```bash
# Set mic gain (run on every boot - does not persist)
amixer -D hw:0 sset 'Mic' 10dB

# Record 5 seconds to RAM disk
arecord -D mic_sv -f S32_LE -r 48000 -c 2 -d 5 /dev/shm/test.wav

# Check if recording has audio
sox /dev/shm/test.wav -n stat 2>&1
```

### Speaker
```bash
# Test speaker with sine tone
speaker-test -D pwm_sv -t sine -f 1000 -c 2

# Initialise volume control (must run before amixer)
speaker-test -D pwm_sv -t sine -f 1000 -c 2 -d 1

# Set speaker volume (0-100%)
amixer -c 1 cset numid=1 50%

# Play a WAV file
aplay -D pwm_sv yourfile.wav
```

### Gain / Volume UI
```bash
# Visual mixer for mic (card 0)
alsamixer -c 0

# Visual mixer for speaker (card 1)
alsamixer -c 1
```

### Save ALSA settings
```bash
sudo alsactl store
```

## Notes

- **Mic gain does not persist across reboots** — add `amixer -D hw:0 sset 'Mic' 10dB` to your startup script
- **Speaker volume control only appears after first use** of `pwm_sv` device
- The SPH0645 produces a **thump on power-on** and has a small **DC offset** — these are hardware characteristics
- PWM audio is noisier than I2S DAC — consider a PCM5102A DAC for better quality audio output
